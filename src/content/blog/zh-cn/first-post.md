欢迎来到你的新 Astro 博客。这是一篇虚构的阅读笔记，你可以修改或删除它。内容不包含真实账户资料或私人信息。

## 这一周的小计划

我想每天留一点时间阅读。与其要求自己读完整本书，不如从一个章节开始，再写下一个有用的想法。

1. 选一个自己感兴趣的主题。
2. 阅读十五分钟。
3. 用自己的话记下学到的内容。

> 今天写下的一小段笔记，可以成为明天继续思考的起点。

## 一个简单的 TypeScript 示例

代码块用于展示示例，这段代码不会在读者的浏览器中执行。

```ts
type ReadingGoal = {
  topic: string;
  minutesPerDay: number;
};

const goal: ReadingGoal = {
  topic: '清楚表达',
  minutesPerDay: 15,
};
```

## 把这篇文章改成自己的内容

打开 `src/content/blog/zh-cn/first-post.md`，修改标题、摘要、日期与正文，然后保存。将「示例作者」改成你愿意公开的名字。文件开头两条 `---` 之间的区域是文章配置。

这篇示例另有英文和繁体中文版本。同一篇文章的翻译请在 `en`、`zh-tw`、`zh-cn` 目录使用相同文件名。对应标签的排列顺序也要一致，语言切换才能正确配对。

执行 `pnpm dev` 预览修改，再执行 `pnpm build` 检查网站产物。发布前执行 `pnpm selfcheck`。不要把密码、token 或私人笔记放入文章与图片：这里发布的内容都能被访客阅读。

你可以浏览[所有文章](/zh-cn/posts/)，或试试[搜索](/zh-cn/search/)。
