歡迎來到你的新 Astro 部落格。這是一篇虛構的閱讀筆記，你可以修改或刪除它。內容不包含真實帳戶資料或私人資訊。

## 這一週的小計畫

我想每天留一點時間閱讀。與其要求自己讀完整本書，不如從一個章節開始，再寫下一個有用的想法。

1. 選一個自己感興趣的主題。
2. 閱讀十五分鐘。
3. 用自己的話記下學到的內容。

> 今天寫下的一小段筆記，可以成為明天繼續思考的起點。

## 我的範例閱讀清單

| 主題 | 計畫 | 進度 |
| --- | --- | --- |
| 清楚表達 | 閱讀一個章節 | 已開始 |
| 整理筆記 | 試著撰寫每週摘要 | 待進行 |

你可以用**粗體文字**標示重要想法，用*斜體*強調語氣，也可以用清單整理相關項目。

## 一個簡單的 TypeScript 範例

程式碼區塊用來展示範例，這段程式不會在讀者的瀏覽器中執行。

```ts
type ReadingGoal = {
  topic: string;
  minutesPerDay: number;
};

const goal: ReadingGoal = {
  topic: '清楚表達',
  minutesPerDay: 15,
};
```

## 把這篇文章改成自己的內容

開啟 `src/content/blog/zh-tw/first-post.md`，修改標題、摘要、日期與內文，然後儲存。將「範例作者」改成你願意公開的名字。檔案開頭兩條 `---` 之間的區塊是文章設定。

這篇範例另有英文和簡體中文版本。同一篇文章的翻譯請在 `en`、`zh-tw`、`zh-cn` 目錄使用相同檔名。對應標籤的排列順序也要一致，語言切換才能正確配對。

執行 `pnpm dev` 預覽修改，再執行 `pnpm build` 檢查網站產物。發布前執行 `pnpm selfcheck`。不要把密碼、token 或私人筆記放入文章與圖片：這裡發布的內容都能被訪客閱讀。

你可以瀏覽[所有文章](/zh-tw/posts/)，或試試[搜尋](/zh-tw/search/)。
